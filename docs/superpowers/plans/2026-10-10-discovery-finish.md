# Design foundation and discovery finish

Approved scope: stages 1 and 2. The four boards supplied by the user are the final visual target; img01.png governs home and img02.png governs explore. This is an internal delivery package, not completion of the entire product.

## Acceptance

- Compact panoramic home hero, genuine resumable progress or a real featured work. Four categories in one mobile row. No invented progress or inferred manhwa classification.
- Three-column grouped desktop updates; vertical mobile list, larger actual cover crops and working chapter links. Independent editorial work cards with genuine collection context and deduplicated work destinations.
- Explore: right desktop sidebar, four desktop / two mobile cover columns, compact icon categories, search/history/URL filters/sort/clear/empty-state preserved.
- Retain brand, Arabic typography, palette, auth/current role and notifications. Remove misleading decorative controls; preserve working shelf controls on work pages.
- Original illustrative covers for existing fictional demo titles only. No uploaded cover replacements, screenshot crops or claims about licensed publications. Source prompts in docs/demo-cover-art.md.

## Execution and review budget

Antigravity receives one bounded UI brief (8 minute print timeout). If it writes no edits, inspect the outcome and complete locally rather than restart an open-ended worker. One combined Claude read-only review receives the actual diff and new source files. One isolated production build and focused discovery/browser run; inspect desktop and mobile together. Fix actionable defects in one batch and confirm affected checks only. No broad repeat reviews or repeated complete test suite for visual changes.

No live migration, push, deployment, SEO work or redesign of work/reader pages in this package. Their shared covers/navigation may improve as a consequence of the foundations.
